# Xiao Fei Hou Skills

AI agent skills for AI filmmaking with MiniMax H3, FeiHou Easy H3 and Seedance. Each zip unpacks to one skill folder. Put the folder in your agent's skills directory, for example `~/.claude/skills/` (Claude Code), `~/.codex/skills/` (Codex), `~/.agents/skills/` (generic) or `~/.workbuddy/skills/` (WorkBuddy), then start a new conversation.
