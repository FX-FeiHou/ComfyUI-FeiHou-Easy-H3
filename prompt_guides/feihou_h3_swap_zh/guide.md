- 【强制】明确写清楚视频里的背景：在 subject_definitions 的 <Video 1> 行和 [Shot 1] 开头，用一两句具体写出 <Video 1> 当前片段的场景——地点、主要陈设和颜色、光线方向与色调、天气或时间、背景里的人群或物件，再写“背景全部来自 <Video 1>，保持原样”。只写看得到的内容，不编造。

- 全文用肯定句：模型对否定句（不要 / 不能 / 不出现）几乎不执行，反而会把被否定的东西画出来；需要排除时一律用上面的对比句。“很小的深色身影”“看不清”“保持原样”这类说法会让模型直接保留原人物；远景写“小，但轮廓是她的”，被火花、烟雾、眩光遮住时写“被遮挡的部分按 <Subject 1> 补全”。


【三、分段生成规则】

1. 动作迁移按「分镜块」生成：有切点就分块；一个分镜块等于一份提示词 + 一段参考视频时间轴，会存成一个视频文件。15 秒以内的块整块一次采样；15～45 秒的连续镜头分成每段不超过 15 秒的块内分镜（分段点由 @split 给出，放在构图变化处），所有段共用这同一份提示词，各自只拿到 <Video 1>、<Audio 1> 在该时间窗内的片段。因此提示词必须对块内任意一段都成立。

2. 把 <Video 1> 写成“当前提供的参考片段”（the currently supplied fragment），生成片段与参考片段时长相同、逐帧对应。一个连续镜头超过 45 秒时会被拆成多个分镜块，每个块各写一份提示词（内容基本一致），并标 @continue 表示接着上一块。

3. 不写具体时间点的具体动作、镜头或切点（例如“00:02 抬左手”“00:03 切到背影”），不写开场准备动作、结束定格或谢幕；不假设这一段是整段视频的开头或结尾。只写可在任何片段成立的规则：首帧和末帧的姿势、构图与片段的第一帧、最后一帧对应，按参考的顺序和节奏连续完成，片段从中途开始时直接接着做。

【强制】不要写“首帧与 <Video 1> 第一帧一致 / 相同”“the first frame matches / is the first frame of <Video 1>”这类句子：模型会把开头的镜头直接复制成原画面，原人物就留在了第一个镜头里。只能写“首帧的姿势和构图对应 <Video 1> 片段的第一帧，而画中人物从第一帧起就已经是 <Subject 1>”。

4. 镜头：只写一个连续镜头 [Shot 1]，不切镜、不加时间戳；一个分镜块就是一个镜头。明确写目标视频是当前片段 <Video 1> 这个单一连续镜头的逐帧编辑：机位、景别、构图、运镜、背景和光线都与这个镜头相同，整段由 <Subject 1> 出演。不要写“<Video 1> 切镜时目标视频同步切镜”这类句子，也不要写镜头列表。
- 兜底：万一当前片段里仍然有切镜（用户没有按镜头分块），就补一句“目标视频在同样的位置切到同样的新镜头（同样的景别、机位和背景），并继续由 <Subject 1> 出演”，不写具体切点时间。

5. 关键帧只是对这段动作风格、镜头和取景的证据：可以概括动作类型、幅度、速度、是否转身、运镜和景别，但不要把关键帧当成完整动作清单逐条复述，也不要据此写切镜。

【四、动作还原要点】

1. 人物、动作、场景分开定义。动作单独定义为一个 Subject（动作序列，从 <Video 1> 抽象），明确它迁移给 <Subject 1>，使用 attribute_transfer。

2. 写清动作还原的要求：肩、肘、腕、手、头、躯干、髋、膝、脚与参考对应部位同步；手的高度和方向、肘的伸展、前臂角度、躯干转向在对应时刻一致；保持源画面中的左右关系，不镜像；停顿保持停顿，快速动作保持快速；重心转移和转向保留源时序；不增加预备动作、不重复动作、不在片段末尾压缩动作。

3. 动作只来自 <Video 1> 的 RGB 画面：手臂、肘部、躯干角度、支撑腿和前后遮挡都按 <Video 1> 对应时刻还原；头发和服装轮廓以 <Subject 1> 为准。

4. 次级运动跟随真实动作：头发、裙摆、外套下摆、饰物有自然的惯性摆动，服装保持可辨认。

5. 替换源人物的身份：用对比句写“原人物的脸、发型发色、服装、首饰、体形 → 换成 <Subject 1> 的对应样子”。画面写成干净的成片画面，代替字幕、水印、Logo、界面元素。


【五、目标人物、背景与表情】

1. 目标人物：根据 <Picture 1> 实际可见内容，用中文具体描述外貌、发型发色、眼睛、服装各层（颜色、材质、款式、纽扣等细节）、鞋子、配饰和画风（写实、二次元赛璐珞、3D 等），在 subject_definitions 中写完整，在 detailed_description 首次出场时简要复述关键特征，之后只用 <Subject N> 指代。看不清的细节不编造。有全身图和脸部特写两张图时，写明分工：脸、五官、脸型和妆容按特写，发型、身形和服装按全身图。人物图自带背景（灰色或白色纯色底、车厢、街道、房间）或水印文字时，写明「人物图的原背景和水印文字都不进画面，画面背景是 <Video 1> 的场景」。

2. 背景：完全沿用 <Video 1> 当前片段，按第二部分的强制项写清具体内容；写明“<Picture 1> 只用来认人，画面里的背景全部来自 <Video 1>”；<Picture 1> 是纯色底（如灰底）时，写明“它的纯色底只是抠图底色，画面背景是 <Video 1> 的场景”。

3. 表情与嘴部：表情跟随原片，写一次即可。默认目标人物嘴唇自然闭合或保持源视频中的轻微表情（如微笑），不说话、不唱歌、不对口型、不跟着 <Audio 1> 张嘴；原声中的人声和歌词都是画外录音。原片里原人物在唱歌或说话、或我明确要求时，写嘴型跟随原声。

4. 写实素材时，detailed_description 第一句写真实画质：像专业相机实拍的真人视频，皮肤有真实的纹理和毛孔，发丝和服装材质（如蕾丝花纹）清晰，光影、景深和反光符合真实环境，动作流畅、重心稳定。二次元、3D 等画风按它的画风写，不套这句。

5. 光线、曝光、画风和人物比例在整段保持一致；目标人物的光照与 <Video 1> 当前镜头的光线一致。


【六、音频规则】

1. 成片音轨直接使用源视频原声对应的片段（audio reuse）。

2. retention_analysis 中 <Audio 1> 使用 partially_copy：成片使用按片段时长截取的原声，不新增环境音、对白、音效或配乐。

3. overall_soundscape 只写“仅使用复用原声中已有的声音，不生成新的环境音、脚步、风声、对白”。non_diegetic_music 写“复用原声，保持原有节奏和时序，不重新作曲、不重排、不重启、不淡入淡出替换音乐；原声人声视为背景播放，画面人物不对口型”。

4. 不把原声中的歌词或对白写进 <d>；目标人物没有台词，不分配 (S1) 等说话人编号。

5. 参考素材列表里没有 <Audio 1>（原声不送入模型，由「动作迁移收束」直接输出原声）时：不写 <Audio 1> 的定义和 retention_analysis 行，任务类型写 [video editing]（去掉 + audio reuse）；overall_soundscape 和 non_diegetic_music 用一句话写成片该有的声音（如「节奏明快的流行舞曲，节拍与舞步一致」），不引用任何 <Audio N>。

【七、固定输出格式（H3 Ref2VA 六段式）】

【八、交付前自行核对】

1. 六个字段齐全、顺序正确、各一次；正文是中文，标签、字段名、保留关系标记和任务类型都是英文；无 markdown，无任何 @ 引用，没有 <图片 1>、<视频 2> 这类中文标签。

8. 我的补充要求（画风、背景、表情、是否唱歌等）已全部体现。
9. 镜头只有一个 [Shot 1]、没有镜头列表、没有写“切镜时同步切镜”（只有片段内仍可能有切镜时才写兜底句）。
10. 有表演者的镜头全文是肯定句和对比句；没有「保持原样 / 原样输出」，没有堆叠的强表情指令；写了原人物的动作；<Video 1> 标的是 weak_reference。
11. 参考图编号与本次实际送入的一致（只送一张图时它就是 <Picture 1>，人物写 <Subject 1>）；参考图是拼图时写明了每一栏的含义和本镜取哪一栏。
12. 参考素材列表里没有 <Audio 1> 时，全文确实没有写它，任务类型和音频字段按第六部分第 5 条写。

【九、实测要点（2026-10-24 / 25 真机）】

1. 换不掉人的根因通常不在措辞：一张脸占满画面的特写、远景逆光里的小人，基础 Ref2VA 会照抄原视频，改写提示词几乎没有影响；工作流里加 Character Swap LoRA v1.5、换几个种子才解决。所以提示词的目标是“清楚、不自相矛盾”，不必为了强行换人堆砌长句。
2. 强烈的表情指令会压制替换：表情跟着原片走，写一次即可，不要把“张大嘴尖叫、眼睛睁大、双手贴脸”这类描述反复堆叠。
3. 有表演者的镜头不要写「保持原样 / 原样输出 / 与原片一致」：这类话会把原人物一起保留；只有画面里没有要换的人（纯观众、空镜）时才这样写。
4. 写清原人物在做什么（起跳、叉腰、推墨镜、转身）：不写动作，动作就不会被复制。
5. 多人同框时写清换哪一位：位置 + 外观 + 动作（“画面右边那位深色卷发、穿玫红上衣、双手捂嘴哭的女观众”），不写位置模型不知道换谁。
6. 只送一张参考图时，节点会把它改编号成 <Picture 1>，人物也写 <Subject 1>，编号对齐。
7. 参考图是拼图（左正面右背面、左不戴墨镜右戴墨镜）时：在 subject_definitions 写明每一栏的含义，说明拼图的分栏、灰底和站姿不进入画面，并写本镜按什么状态取哪一栏（墨镜戴着 / 推下 / 拿在手里 / 不戴）。
8. 换上去的人和原表演者服装接近时（同样是亮片外套、银腰带），对比句也要**逐件**写清：头发 → 头发、外套 → 外套、裤子 → 裤子、鞋 → 鞋、手套 → 手套，并写“从头到脚整个人替换”。实测：只写“服装接近，差别主要在头部”时，H3 **只换了头**，身体保留了原表演者的外套、金色内搭和裤子。
9. 每一块有表演者的提示词都写一句“从这一块的第一帧起、每个镜头的第一帧起，台上的人从头到脚已经是 <Subject 1>”。实测：缺这句时镜头开头先照抄原人物 1 秒多，再慢慢变成她。
10. 一块里有多个镜头时，每个有表演者的 [Shot N] 都套一遍完整的短模板（第一帧起、换谁、换成谁、一句对比、动作、保留场景）。下面是这条规则的由来——
    旧写法：**把每一个有表演者的 [Shot N] 当成一个独立分块来写**，按这个顺序写全：①这一镜的机位、景别、光线和背景（先写场景，不提人）；②**和第 1 个镜头一样完整的对比句**（“原片里台上是……（原人物全身装扮）；画面里用 <Subject 1> 从头到脚整个人替换掉他——（她的全身装扮）。每一件都换成她的：……”）；③原人物在这一镜的完整动作；④远景再加轮廓锚点。不要用缩写句代替（例如“这个镜头从第一帧起就是她：原片里这一镜还是那位男性表演者……”——“还是”会被读成保留原人物）。实测：第 2 个镜头只写一句“切到另一个机位，她在追光下走动”时，切镜后的开头又变回原人物——硬切处模型会重新读原片，后面的镜头不会继承第 1 个镜头的替换说明。
