【三、分段生成规则】

1. 动作迁移按「分镜块」生成：有切点就分块；一个分镜块等于一份提示词 + 一段参考视频时间轴，会存成一个视频文件。15 秒以内的块整块一次采样；15～45 秒的连续镜头分成每段不超过 15 秒的块内分镜（分段点由 @split 给出，放在构图变化处），所有段共用这同一份提示词，各自只拿到 <Video 1>、<Audio 1> 在该时间窗内的片段。因此提示词必须对块内任意一段都成立。

2. 把 <Video 1> 写成“当前提供的参考片段”（the currently supplied fragment），生成片段与参考片段时长相同、逐帧对应。一个连续镜头超过 45 秒时会被拆成多个分镜块，每个块各写一份提示词（内容基本一致），并标 @continue 表示接着上一块。

3. 不写具体时间点的具体动作、镜头或切点（例如“00:02 抬左手”“00:03 切到背影”），不写开场准备动作、结束定格或谢幕；不假设这一段是整段视频的开头或结尾。只写可在任何片段成立的规则：首帧和末帧的姿势、构图与片段的第一帧、最后一帧对应，按参考的顺序和节奏连续完成，片段从中途开始时直接接着做。

【强制】不要写“首帧与 <Video 1> 第一帧一致 / 相同”这类句子：模型会把开头直接复制成原视频的画面（原人物和原背景）。只能写“首帧的姿势和构图对应 <Video 1> 片段的第一帧，而画中人物从第一帧起就是 <Subject 1>、背景从第一帧起就是第二部分确定的场景”。

4. 镜头：只写一个连续镜头 [Shot 1]，不切镜、不加时间戳；一个分镜块就是一个镜头。构图和运镜按 <Video 1>（固定机位写 static camera）。

5. 关键帧只是对这段动作风格、镜头和取景的证据：可以概括动作类型、幅度、速度、是否转身、运镜和景别，但不要把关键帧当成完整动作清单逐条复述，也不要据此写切镜。

【四、动作还原要点】

1. 人物、动作、场景分开定义。动作单独定义为一个 Subject（动作序列，从 <Video 1> 抽象），明确它迁移给 <Subject 1>，使用 attribute_transfer。

2. 写清动作还原的要求：肩、肘、腕、手、头、躯干、髋、膝、脚与参考对应部位同步；手的高度和方向、肘的伸展、前臂角度、躯干转向在对应时刻一致；保持源画面中的左右关系，不镜像；停顿保持停顿，快速动作保持快速；重心转移和转向保留源时序；不增加预备动作、不重复动作、不在片段末尾压缩动作。

3. 动作只来自 <Video 1> 的 RGB 画面：手臂、肘部、躯干角度、支撑腿和前后遮挡都按 <Video 1> 对应时刻还原；头发和服装轮廓以 <Subject 1> 为准。

4. 次级运动跟随真实动作：头发、裙摆、外套下摆、饰物有自然的惯性摆动，服装保持可辨认。

5. 动作只写一句：「<Subject 1> 照着 <Video 1> 跳舞（或表演）：每个动作、身体朝向、左右方向和节奏都与 <Video 1> 同一时刻一致；机位和景别跟随 <Video 1>」。不列动作清单，不写「转身」「背对镜头时……」这类具体动作或朝向。实测：写了一句「身体转向侧面或背对镜头时……」，原舞者没有转身，生成的人物却转了身。

【六、音频规则】

4. 不把原声中的歌词或对白写进 <d>；目标人物没有台词，不分配 (S1) 等说话人编号。

5. 参考素材列表里没有 <Audio 1>（原声不送入模型，由「动作迁移收束」直接输出原声）时：不写 <Audio 1> 的定义和 retention_analysis 行，任务类型写 [reference generation]（去掉 + audio reuse）；overall_soundscape 和 non_diegetic_music 用一句话写成片该有的声音（如「节奏明快的流行舞曲，节拍与舞步一致」），不引用任何 <Audio N>。
