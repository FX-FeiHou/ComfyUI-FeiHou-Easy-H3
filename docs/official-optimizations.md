# 可选官方优化（标准版）

主节点高级选项在完整低显存分块上方提供默认关闭的“参考素材仅文本编码”开关。内置官方稀疏注意力开关已移除，请使用官方 Model Sparse Attention 节点自行调参。

- **参考素材仅文本编码（不生成参考 latent）**：参考条件保留图像/视频的多模态文本编码与引用编号，但不调用参考图、视频及音频的 VAE 编码。仍然生成目标 latent。与官方参考节点不接参考 VAE 的语义一致，会改变参考保真度；音频标签仍在，但原声音频波形条件不再输入模型，不适合需要保持音色/原声的任务。独立 Audio1 输出和截取范围不变。

官方 Model Sparse Attention 可以与 ModelAttentionBackend 共存；后者选择稀疏未生效时的稠密注意力实现。使用外接官方稀疏时，请关闭 Easy 的完整低显存分块，避免叠加 DiT block 替换。仅文本编码开关只改变参考条件路径，不移除普通单采图生/首尾帧条件。

关闭高级选项时仅文本编码不生效。旧的保存参数位置不变，新参数只在序列末尾追加，显示顺序独立调整。兼容短暂包含稀疏开关的工作流保存序列，移除稀疏项不会误开仅文本编码。RH 版不包含此次修改。
